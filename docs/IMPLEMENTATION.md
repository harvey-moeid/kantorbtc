## Kebijakan implementasi sementara

Bagian 21 PRD belum final. Aplikasi tidak memilih angka TTL atau margin tie-breaker secara diam-diam. Admin perlu menetapkannya. Pelacakan awal mengandalkan tick teramati, TTL terus berjalan, TP terakhir menutup sinyal, dan belum melakukan pembatalan otomatis pada konflik. Tidak ada klaim profit, kualitas sinyal, lisensi publik, atau kemampuan eksekusi order.

## Pengujian dalam sesi implementasi

- Build TypeScript/Vite produksi dan 161 tes otomatis lulus; enam tes jaringan opsional dilewati pada suite default dan lulus saat dijalankan terpisah pada sesi implementasi awal.
- Tes engine, crypto, structure, upstream state machine, timeline presentasi/waiting, jalur tangga/rutinitas, kebijakan FPS, validasi payload, reconnect, dan broadcast privat/publik.
- Edit alert: 16 kasus API/pemicuan dengan middleware asli dan SQLite in-memory dari migrasi, serta 5 kasus state untuk demo, kegagalan server, logout/perpindahan demo, dan penghapusan selama save. Uji API memeriksa otorisasi/origin, validasi, persistensi, serta kondisi update atomik yang mempertahankan status one-shot. Feed hanya memicu level yang masih sama dengan saat dibaca; tick dengan level lama setelah edit/hapus/nonaktif tidak memicu pengiriman.
- CI/CD: 15 kasus generator untuk target production, nama, path, D1, mode live, dan metadata credential; workflow diperiksa dengan actionlint. Runner CI browser diuji terhadap D1 sementara, dan packaging konfigurasi production diperiksa lewat Wrangler dry run. Eksekusi GitHub Actions dan deployment account Cloudflare perlu diverifikasi setelah workflow digabung dan kredensial target dikonfigurasi.
- Smoke alert Chromium: edit numerik, harga invalid, drag dengan konfirmasi/batal, keyboard, perubahan indikator, isolasi BTC/emas, label ID/EN, hapus garis, demo tanpa write API, serta drag sentuhan viewport 390 px tanpa overflow.
- D1 lokal: migrasi, auth/session revoke, settings/audit persistence, validasi, credential write-only, alert CRUD, origin rejection.
- Chromium desktop dan mobile 390 px: routes dan interaksi utama, WebGL scene, chart, tanpa overflow atau error JavaScript setelah perbaikan label sprite.
- Smoke meeting: empat AI berbicara bergilir, RR/bos, kamera/manual floor, rekaman scanner ditolak melewati AI, pause/seek/kecepatan, simulasi tab tersembunyi, ponsel/reduced motion, payload publik yang disisipi data privat, serta reconnect.
- Adapter BTC nyata: ticker OKX dan candle lima timeframe lulus enam tes baca; tidak menggunakan key atau mengirim order.
- Runtime live terisolasi: Worker dengan D1 sementara, tanpa cron/key AI/Discord, menerima stream BTC Bybit cadangan dan menyimpan quote baru. 17 event publik diperiksa tanpa angka harga. Mode utama tetap demo.
- Wrangler lokal biasa tidak meneruskan outbound workerd melalui proxy; DNS provider gagal. Runner Miniflare menggunakan `outboundService`, proxy HTTP/WebSocket lingkungan, dan verifikasi TLS standar. Remote Worker belum diperiksa.

Target prioritas berikutnya adalah validasi akun emas/AI dan deployment nyata, penyelesaian aturan PRD bagian 21, gold streaming, gap recovery/backfill quota, fallback derivatives/provider AI, i18n seluruh panel/Discord, aset karakter rigged, serta pengukuran perangkat HP.
