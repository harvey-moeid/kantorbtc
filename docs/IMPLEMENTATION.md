## Kebijakan yang dikonfirmasi pemilik

PRD 20.11–20.12: TTL opsi A, stop setelah entry, gold hanya waktu pasar buka/status provider (unknown dijeda), margin 40, strict 3-vote/valid 2–2, cancel waiting same-TF, cross-TF mandiri, struktur cancel nonaktif, exit TP1, OHLC ambigu tidak ditebak, formal SMC dan proxy volume verified, total 13 karakter. Sisa budget gold dan pause/resume disimpan dalam JSON sinyal. Legacy tanpa clock diinisialisasi dari sisa deadline yang tersedia, tanpa merekonstruksi penutupan yang tidak tercatat.

`ambigu` berarti hasil tidak diketahui. Candle sebelum exit yang diketahui dapat menyebabkan koreksi hasil ke ambigu, tanpa menghapus peristiwa harga exit lama. Candle yang menyentuh level lain setelah tick exit tidak mengubah hasil. Tick setelah gap tidak menyelesaikan urutan TP/SL yang hilang.

Tidak ada klaim profit, lisensi publik, SLA produksi atau eksekusi order. Bobot/fitur scanner lanjutan, akun/provider nyata dan perangkat target masih memerlukan verifikasi.

## Pengujian dalam sesi implementasi

- Build TypeScript/Vite produksi dan 318 tes otomatis lulus; enam tes jaringan opsional dilewati pada suite default dan lulus saat dijalankan terpisah pada sesi implementasi awal.
- Tes engine, crypto, structure, upstream state machine, timeline presentasi/waiting, jalur tangga/rutinitas, kebijakan FPS, validasi payload, reconnect, dan broadcast privat/publik.
- Edit alert: 16 kasus API/pemicuan dengan middleware asli dan SQLite in-memory dari migrasi, serta 5 kasus state untuk demo, kegagalan server, logout/perpindahan demo, dan penghapusan selama save. Uji API memeriksa otorisasi/origin, validasi, persistensi, serta kondisi update atomik yang mempertahankan status one-shot. Feed hanya memicu level yang masih sama dengan saat dibaca; tick dengan level lama setelah edit/hapus/nonaktif tidak memicu pengiriman.
- CI/CD: 14 kasus generator untuk target, nama, path, D1, mode demo, dan metadata credential; workflow diperiksa dengan actionlint. Runner CI browser diuji terhadap D1 sementara, dan packaging konfigurasi staging/production diperiksa lewat Wrangler dry run. Eksekusi GitHub Actions dan deployment account Cloudflare perlu diverifikasi setelah workflow digabung dan kredensial target dikonfigurasi.
- Smoke alert Chromium: edit numerik, harga invalid, drag dengan konfirmasi/batal, keyboard, perubahan indikator, isolasi BTC/emas, label ID/EN, hapus garis, demo tanpa write API, serta drag sentuhan viewport 390 px tanpa overflow.
- D1 lokal: migrasi, auth/session revoke, settings/audit persistence, validasi, credential write-only, alert CRUD, origin rejection.
- Chromium desktop dan mobile 390 px: routes dan interaksi utama, WebGL scene, chart, tanpa overflow atau error JavaScript setelah perbaikan label sprite.
- Smoke meeting: empat AI berbicara bergilir, RR/bos, kamera/manual floor, rekaman scanner ditolak melewati AI, pause/seek/kecepatan, simulasi tab tersembunyi, ponsel/reduced motion, payload publik yang disisipi data privat, serta reconnect.
- Adapter BTC nyata: ticker OKX dan candle lima timeframe lulus enam tes baca; tidak menggunakan key atau mengirim order.
- Runtime live terisolasi: Worker dengan D1 sementara, tanpa cron/key AI/Discord, menerima stream BTC Bybit cadangan dan menyimpan quote baru. 17 event publik diperiksa tanpa angka harga. Mode utama tetap demo.
- Wrangler lokal biasa tidak meneruskan outbound workerd melalui proxy; DNS provider gagal. Runner Miniflare menggunakan `outboundService`, proxy HTTP/WebSocket lingkungan, dan verifikasi TLS standar. Remote Worker belum diperiksa.

Milestone 12 Oktober 2026: stream OANDA, recovery primary/REST, derivatives fallback, provider AI cadangan, gap recovery/backfill atomik, TTL pilihan A dan stop setelah entry sudah diimplementasikan. Tambahan 62 tes meliputi API privat/audit, baseline exchange, NDJSON/freshness/reconnect, quote serial/status, migrasi TTL, serta rekonsiliasi candle. Seluruh smoke browser kembali lulus pada Chromium desktop dan ponsel 390 px. Semua hasil provider pada milestone ini memakai transport fixture; bukan pembuktian akun emas/AI atau SLA produksi.

Target prioritas berikutnya adalah validasi akun emas/AI dan deployment nyata, penyelesaian aturan PRD bagian 21, status/freshness emas pada akun nyata dan backfill quota/coverage, verifikasi CFTC dan anggaran AI, sisa i18n panel/validasi, aset karakter rigged, serta pengukuran perangkat HP.

COT (12 Oktober 2026): keputusan pemilik adalah konteks meeting AI XAUUSD saja; tidak mengubah scanner, threshold, quorum, atau tie-breaker. Sumber: CFTC Disaggregated Futures Only `72hh-3qpy`, kontrak COMEX gold `088691`, kategori Managed Money; long/short/spreading/open interest dalam kontrak. Net = long − short; perubahan hanya dihitung jika kedua tanggal laporan terpaut tepat tujuh hari. Tanggal posisi tidak disebut tanggal publikasi, dan rilis Jumat tidak diasumsikan saat ada keterlambatan/libur. Pemeriksaan tiap enam jam melalui lease atomik D1, sebelum cron memanggil scan; timeout 12 detik dan body maksimal 64 KiB. Gagal fetch/validasi mempertahankan cache dengan peringatan. Freshness konservatif: tanggal posisi maksimal 14 hari dan pengambilan sukses maksimal tujuh hari; stale/unavailable tidak membawa angka posisi ke prompt AI. Snapshot meeting memuat sumber, tanggal, waktu fetch/check, status, dan peringatan, sehingga replay tidak memakai laporan terbaru. Endpoint privat GET `/api/market/XAUUSD/cot` membaca cache tanpa fetch. Migrasi 0009 menambahkan laporan/sync; demo tidak mengunduh atau mengarang COT. Tambahan 19 tes mencakup parsing, validasi, cooldown konkurensi, persistensi/failure, freshness, auth, serta penyaringan prompt fresh/stale/BTC. Schema laporan diperiksa terhadap portal CFTC, tetapi akses API langsung belum berhasil; fixture bukan bukti konektivitas produksi.

Smoke lifecycle/COT lulus di Chromium: laporan fresh/stale, tanggal posisi dan sumber, label Inggris, serta detail ponsel 390 px tanpa overflow atau error JavaScript. Ketiga smoke browser lain lulus pada run yang sama; pengulangan terakhir hanya smoke lifecycle/COT setelah fixture bahasa diperbaiki. Sumber schema: [portal resmi CFTC Disaggregated Futures Only](https://publicreporting.cftc.gov/w/72hh-3qpy/default).
